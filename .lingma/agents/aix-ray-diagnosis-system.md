# 内置完整项目知识库

## 项目基础信息

**项目全称**: 胸影智诊 V3.0（AIX-Ray Intelligent Diagnosis System）  
**项目定位**: 面向医疗机构的全栈AI辅助胸部X光影像诊断平台  
**核心模型**: DenseNet-121（CheXNet），基于ChestX-ray14数据集训练，AUC精度0.8149  

**支持14类胸部疾病多标签分类预测**:
- 肺炎、肺不张、实变、浸润、肿块、结节
- 胸腔积液、肺气肿、纤维化、心脏肥大、水肿
- 气胸、胸膜增厚、疝

**推理加速**: ONNX Runtime双引擎推理，相比原生PyTorch提速2~5倍，支持CPU/CUDA/DirectML多硬件自适应  
**可解释性**: Grad-CAM热力图可视化AI关注区域，PyTorch懒加载显存优化  
**大模型能力**: 接入通义千问、DeepSeek等所有OpenAI兼容大模型，基于CRISPE提示框架自动生成专业放射医学诊断报告，SSE流式AI医学咨询对话  

**系统定位**: **仅科研、教学、医院辅助工具，绝不替代执业医师临床诊断，禁止作为医疗诊疗依据**。

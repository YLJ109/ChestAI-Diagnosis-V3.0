## 📝 常见问题

### Q1: 识别失败，提示"未检测到人脸"

**原因**：
- 光线不足
- 面部角度过大
- 距离太远/太近

**解决**：
- 调整光线，确保面部清晰
- 正面朝向摄像头
- 保持 50-80cm 距离

### Q2: 录入时提示"未检测到人脸"

**原因**：
- 照片质量差
- 照片中无人脸
- 人脸被遮挡

**解决**：
- 使用高质量正面照
- 确保无墨镜、口罩遮挡
- 分辨率建议 640x480 以上

### Q3: CUDA 不可用，使用 CPU 模式

**说明**：这是正常的，InsightFace 在 CPU 模式下也能工作，只是速度稍慢（~150ms vs ~50ms）。

**如需启用 GPU**：
```bash
pip install onnxruntime-gpu>=1.19.0
# 需要 NVIDIA 驱动支持 CUDA 11.x/12.x
```

## 🎓 最佳实践

### 照片采集规范

1. **拍摄环境**：
   - 室内光线充足
   - 背景简洁（白色/浅色）
   - 无强烈逆光

2. **患者姿势**：
   - 正面朝向镜头
   - 头部正直，不倾斜
   - 表情自然，双眼睁开

3. **技术要求**：
   - 分辨率 ≥ 640x480
   - 格式：JPG/PNG
   - 文件大小 ≤ 5MB
   - 面部占比 ≥ 30%

### 系统维护

1. **定期备份**：
   ```bash
   # 备份数据库
   cp backend/data/aixray.db backend/data/aixray_backup_$(date +%Y%m%d).db
   ```

2. **监控日志**：
   - 查看后端日志：`backend/logs/`
   - 关注识别失败率
   - 监控 API 响应时间

3. **数据清理**：
   - 定期清理无效人脸数据
   - 归档离职员工/出院患者数据

# 二维码扫描特效说明

## ✨ 已实现的视觉特效

### 1️⃣ **扫描线动画**（持续扫描中）

#### 视觉效果：
- 📍 一条蓝绿色渐变光带从上到下循环移动
- 💫 带有发光效果（box-shadow）
- 🔄 每 2 秒完成一次往返扫描
- 🎯 透明度渐变，模拟真实扫描仪

#### 技术实现：
```css
.scan-line {
  position: absolute;
  height: 3px;
  background: linear-gradient(90deg, 
    transparent 0%, 
    rgba(34, 211, 238, 0.8) 20%, 
    rgba(34, 211, 238, 1) 50%,     /* 中心最亮 */
    rgba(34, 211, 238, 0.8) 80%, 
    transparent 100%);
  box-shadow: 0 0 10px rgba(34, 211, 238, 0.8),
              0 0 20px rgba(34, 211, 238, 0.4);
  animation: scanLineMove 2s ease-in-out infinite;
}

@keyframes scanLineMove {
  0%, 100% { top: 10%; opacity: 0; }  /* 起始/结束：透明 */
  10%      { opacity: 1; }             /* 淡入 */
  90%      { opacity: 1; }             /* 保持可见 */
  50%      { top: 85%; }               /* 移动到下方 */
}
```

### 2️⃣ **四角脉冲动画**（扫描框装饰）

#### 视觉效果：
- 📐 四个角落有 L 形边框标记
- 💓 依次脉冲放大（左上 → 右上 → 右下 → 左下）
- 🌊 每个角延迟 0.5 秒，形成波浪效果
- ✨ 透明度从 0.6 到 1.0 循环变化

#### 技术实现：
```css
.corner-scan {
  position: absolute;
  width: 30px;
  height: 30px;
  border-color: rgba(34, 211, 238, 0.8);
  border-width: 3px;
  animation: cornerPulse 2s ease-in-out infinite;
}

/* 四个角的延迟 */
.corner-tl { animation-delay: 0s;   }
.corner-tr { animation-delay: 0.5s; }
.corner-br { animation-delay: 1s;   }
.corner-bl { animation-delay: 1.5s; }

@keyframes cornerPulse {
  0%, 100% { opacity: 0.6; transform: scale(1);   }
  50%      { opacity: 1;   transform: scale(1.1); }  /* 放大 10% */
}
```

### 3️⃣ **成功对勾动画**（识别成功后）

#### 视觉效果：
- ✅ 绿色圆形边框逐渐绘制（0.6 秒）
- ✔️ 对勾线条随后绘制（0.4 秒，延迟 0.4 秒）
- 🎆 整体弹出动画（弹性缩放）
- 💚 外框变为绿色并添加光晕

#### 技术实现：
```css
/* SVG 圆形绘制 */
.checkmark-circle {
  stroke: #10b981;
  stroke-dasharray: 166;     /* 圆周长 */
  stroke-dashoffset: 166;    /* 初始完全隐藏 */
  animation: circleStroke 0.6s ease forwards;
}

@keyframes circleStroke {
  to { stroke-dashoffset: 0; }  /* 完全显示 */
}

/* 对勾绘制 */
.checkmark-check {
  stroke: #10b981;
  stroke-dasharray: 48;      /* 路径长度 */
  stroke-dashoffset: 48;     /* 初始隐藏 */
  animation: checkStroke 0.4s 0.4s ease forwards;  /* 延迟 0.4s */
}

@keyframes checkStroke {
  to { stroke-dashoffset: 0; }
}

/* 弹出动画 */
.success-checkmark {
  animation: checkmarkPopIn 0.5s cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

@keyframes checkmarkPopIn {
  0%   { transform: translate(-50%, -50%) scale(0); opacity: 0; }
  100% { transform: translate(-50%, -50%) scale(1); opacity: 1; }
}
```

### 4️⃣ **提示文本切换**

#### 视觉效果：
- 📝 扫描中："请将患者二维码对准摄像头"（蓝色）
- ✅ 成功后："识别成功！正在登录..."（绿色）
- 🎨 背景色和边框色同步变化
- 📈 轻微脉冲放大动画

#### 技术实现：
```vue
<div class="scanner-tips" :class="{ 'success-tip': scanSuccess }">
  <el-icon v-if="!scanSuccess"><InfoFilled /></el-icon>
  <el-icon v-else :size="20" color="#10b981"><CircleCheckFilled /></el-icon>
  <span>{{ scanSuccess ? '识别成功！正在登录...' : '请将患者二维码对准摄像头' }}</span>
</div>
```

```css
.scanner-tips.success-tip {
  background: rgba(16, 185, 129, 0.1);
  border-color: rgba(16, 185, 129, 0.3);
  color: #10b981;
  animation: successPulse 0.6s ease;
}

@keyframes successPulse {
  0%   { transform: scale(1);    }
  50%  { transform: scale(1.05); }  /* 放大 5% */
  100% { transform: scale(1);    }
}
```

## 🎬 完整动画时间线

```
用户点击"开启摄像头"
    ↓
[0ms]     摄像头启动，显示扫描画面
    ↓
[立即]    扫描线开始上下移动（2s 循环）
          四角开始脉冲动画（2s 循环，各角延迟 0.5s）
    ↓
... 用户扫描二维码 ...
    ↓
[识别成功瞬间]
    ↓
[0ms]     scanSuccess = true
          - 扫描线和角标消失（v-if 条件）
          - 外框变绿 + 光晕
          - 提示文本变绿 + 脉冲
    ↓
[0ms]     对勾图标弹出（0.5s 弹性动画）
    ↓
[0ms]     圆形边框开始绘制（0.6s）
    ↓
[400ms]   对勾线条开始绘制（0.4s）
    ↓
[800ms]   等待用户看到成功动画
    ↓
[800ms+]  停止摄像头，执行登录
    ↓
[登录完成] scanSuccess = false，重置状态
```

## 🎯 用户体验优化点

### 1. **即时反馈**
- ✅ 扫描线让用户知道系统在工作
- ✅ 角标脉冲增加科技感
- ✅ 成功动画确认操作完成

### 2. **视觉层次**
- 🔝 扫描线在最上层（z-index: 10）
- 🔝 角标在扫描线同层
- 🔝 成功对勾在最顶层（z-index: 20）
- 📷 摄像头画面在底层

### 3. **性能优化**
- ⚡ 使用 CSS 动画（GPU 加速）
- ⚡ 避免 JavaScript 定时器
- ⚡ 动画完成后自动清理

### 4. **无障碍考虑**
- 👁️ 动画不会过快（2s 周期）
- 👁️ 成功状态有明显颜色对比
- 👁️ 文字提示清晰易懂

# 患者终端黑白主题重构说明

## 重构概述

本次重构将患者终端的页面样式和布局方式完全重新设计，采用**黑白极简医疗终端风格**。

---

## 主要变更

### 1. HomePage.vue（患者主页）

#### 设计特点
- **主题配色**：纯黑白搭配（#000、#fff、#f5f5f5、#e0e0e0、#666、#999）
- **布局方式**：2x2 网格布局，四个功能模块卡片
- **视觉风格**：简洁、专业、易用的医院自助终端风格

#### 功能模块
1. **智能分诊** - 症状分析与科室推荐
2. **AI健康咨询** - 24小时智能医疗问答
3. **报告历史** - 查看历史诊断记录（带数量徽章）
4. **打印报告** - 获取纸质诊断报告（带数量徽章）

#### 交互效果
- **悬停效果**：卡片上移 4px，阴影加深，边框变黑，图标背景反色
- **点击反馈**：轻微上移 2px，模拟按压感
- **箭头指示器**：悬停时向右移动，引导用户点击

#### 删除的旧元素
- ❌ 顶部装饰条
- ❌ 彩色渐变背景
- ❌ 指示点动画
- ❌ 医疗标签组
- ❌ 紧急指示器
- ❌ AI在线状态

---

### 2. MainPage.vue（主框架页面）

#### 顶部导航栏优化
- **Logo区域**：黑色方形图标 + 白色文字
- **移除元素**：
  - ❌ 日期统计信息
  - ❌ AI引擎状态
  - ❌ 主题切换按钮（强制使用浅色主题）
- **保留元素**：
  - ✅ 用户头像和信息
  - ✅ 返回首页按钮（仅在分诊/咨询页面显示）
  - ✅ 退出登录按钮

#### 样式调整
- 背景色：`#f5f5f5`（浅灰色）
- 导航栏：纯白底色 + 黑色边框
- 按钮：黑白对比，悬停反色
- 用户头像：黑色背景 + 白色文字

#### 脚本优化
- 移除主题切换逻辑
- 强制设置为浅色主题
- 简化导入语句

---

## 技术细节

### CSS 变量替换
之前使用的 CSS 变量（如 `var(--patient-primary)`）已全部替换为具体的颜色值：

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主背景 | `#f5f5f5` | 浅灰色背景 |
| 卡片背景 | `#fff` | 纯白色 |
| 边框颜色 | `#e0e0e0` | 浅灰边框 |
| 主文字 | `#000` | 纯黑色 |
| 次要文字 | `#666` | 中灰色 |
| 提示文字 | `#999` | 浅灰色 |
| 悬停背景 | `#fafafa` | 极浅灰 |

### 响应式设计
保留了完整的响应式适配：
- **桌面端**（>1024px）：2列网格，大间距
- **平板端**（768-1024px）：2列网格，中等间距
- **移动端**（<768px）：单列布局，小间距

### 动画效果
- 卡片悬停：`cubic-bezier(0.4, 0, 0.2, 1)` 缓动函数
- 图标缩放：`transform: scale(1.05)`
- 过渡时间：`0.3s`

## 注意事项

1. **主题一致性**：整个患者终端统一使用黑白主题，不再支持深色模式切换
2. **性能优化**：所有动画使用 CSS transform，GPU 加速，性能优异
3. **无障碍访问**：保持足够的颜色对比度（WCAG AA 标准）
4. **浏览器兼容**：支持现代浏览器（Chrome、Firefox、Safari、Edge）

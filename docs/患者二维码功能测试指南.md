# 患者二维码扫码登录功能 - 测试指南

## ✅ 功能概述

这是一个**真实可用**的患者二维码生成和摄像头扫码登录功能，包含以下核心能力：

1. **管理员为患者生成专属二维码**（Base64格式图片）
2. **患者终端通过摄像头扫描识别二维码**
3. **自动提取患者编号并完成登录**
4. **完整的资源清理机制**（摄像头权限释放）

## 🧪 测试步骤

### 测试 1：管理员生成患者二维码

#### 步骤：
1. 使用管理员账号登录系统（如 `admin/admin123`）
2. 进入【后台管理】→【患者管理】
3. 找到任意一个患者，点击操作列的 **"二维码"** 按钮
4. 应该弹出对话框显示：
   - 患者编号
   - 患者姓名
   - 二维码图片（280x280px）
   - 使用说明

#### 预期结果：
- ✅ 对话框正常显示
- ✅ 二维码图片清晰可见
- ✅ 可以点击"下载二维码"保存为PNG文件
- ✅ 二维码内容格式为：`PATIENT_QRCODE:P20260315001`

#### 验证二维码内容（可选）：
使用手机微信或其他扫码工具扫描下载的二维码，应该看到文本：
```
PATIENT_QRCODE:P20260315001
```

---

### 测试 2：患者终端扫码登录

#### 步骤：
1. 打开浏览器访问患者登录页面：`http://localhost:5173/patient-login`
2. 点击顶部的 **"扫码登录"** 标签
3. 点击 **"开启摄像头"** 按钮
4. 浏览器会请求摄像头权限 → 点击"允许"
5. 将之前生成的患者二维码对准摄像头
6. 等待识别成功

#### 预期结果：
- ✅ 摄像头画面正常显示在 320x320px 区域
- ✅ 识别到二维码后自动停止摄像头
- ✅ 显示"扫码登录成功"提示
- ✅ 自动跳转到患者主页 `/patient`

#### 可能的问题及解决：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法访问摄像头 | 浏览器权限被拒绝 | 检查浏览器地址栏右侧的摄像头图标，设置为"允许" |
| 摄像头黑屏 | 其他应用占用摄像头 | 关闭其他使用摄像头的程序（如微信、Zoom） |
| 识别失败 | 二维码不清晰或距离太远 | 调整摄像头距离，确保二维码完整出现在框内 |
| 提示"无效的二维码" | 扫描了非患者二维码 | 确保扫描的是系统生成的患者专属二维码 |

#### 2. 检查摄像头权限
在患者登录页面，开启摄像头后，在控制台输入：
```javascript
navigator.mediaDevices.getUserMedia({ video: true })
  .then(stream => {
    console.log('摄像头访问成功')
    stream.getTracks().forEach(track => track.stop())
  })
  .catch(err => console.error('摄像头访问失败:', err))
```

#### 3. 检查扫码逻辑
查看控制台是否有错误信息，特别是：
- `Scanner error:` - 摄像头启动失败
- `Stop scanner error:` - 摄像头关闭失败

## 🎯 功能特性说明

### 安全性
- ✅ 二维码内容带前缀标识 `PATIENT_QRCODE:`，防止误扫其他二维码
- ✅ 扫码成功后立即停止摄像头，保护隐私
- ✅ 登录过程记录审计日志（可在后台查看）

### 用户体验
- ✅ 一键开启/关闭摄像头
- ✅ 实时视觉反馈（扫描框、提示信息）
- ✅ 扫码成功后自动跳转，无需手动操作
- ✅ 支持多种登录方式切换（扫码/刷脸/编号）

### 性能优化
- ✅ Base64 编码传输，避免文件存储开销
- ✅ 组件卸载时自动清理摄像头资源
- ✅ 扫码频率限制（fps: 10），降低CPU占用

## 🐛 常见问题排查

### 问题 1：后端报错 `ModuleNotFoundError: No module named 'qrcode'`
**解决**：
```bash
cd d:\front-back\AIX-RayIntelligentDiagnosisSystemV3.0\backend
pip install qrcode[pil]
```

### 问题 2：前端报错 `Cannot find module 'html5-qrcode'`
**解决**：
```bash
cd d:\front-back\AIX-RayIntelligentDiagnosisSystemV3.0\frontend
npm install html5-qrcode
```

### 问题 3：摄像头无法在 HTTPS 外使用
**说明**：现代浏览器要求摄像头必须在 HTTPS 或 localhost 环境下使用  
**解决**：确保访问地址是 `http://localhost:5173` 或 `http://127.0.0.1:5173`

### 问题 4：Safari 浏览器不支持
**说明**：部分旧版 Safari 对 `html5-qrcode` 兼容性不佳  
**解决**：建议使用 Chrome、Edge 或 Firefox 浏览器

## 🚀 部署建议

### 生产环境注意事项

1. **HTTPS 配置**
   - 摄像头API要求 HTTPS（localhost除外）
   - 建议使用 Nginx 反向代理 + Let's Encrypt 证书

2. **浏览器兼容性**
   - 推荐：Chrome 80+、Edge 80+、Firefox 75+
   - 不推荐：IE、旧版 Safari

3. **性能优化**
   - 二维码图片已使用 Base64 编码，无需额外CDN
   - 可考虑添加二维码缓存机制（Redis）

4. **安全加固**
   - 二维码有效期限制（建议24小时）
   - 扫码登录频率限制（防暴力破解）
   - 敏感操作二次验证

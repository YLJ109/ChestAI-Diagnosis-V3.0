# 患者二维码功能说明

## 功能概述

为患者生成专属二维码，支持通过电脑摄像头扫码快速登录患者自助终端。

## 使用流程

### 1. 管理员生成患者二维码

1. 登录医护人员管理后台
2. 进入"患者管理"页面
3. 在患者列表中找到目标患者
4. 点击操作列的"二维码"按钮
5. 系统自动生成该患者的专属二维码
6. 可以下载二维码图片并打印给患者

### 2. 患者扫码登录

1. 在患者自助终端选择"扫码登录"方式
2. 点击"开启摄像头"按钮
3. 允许浏览器访问摄像头权限
4. 将患者专属二维码对准摄像头
5. 系统自动识别并登录

## 技术实现

### 后端

**API 接口：**

- `GET /api/v1/auth/patient-qrcode/<patient_id>` - 生成患者二维码
  - 需要认证（医护人员token）
  - 返回Base64编码的二维码图片
  - 二维码内容格式：`PATIENT_QRCODE:{patient_no}`

**依赖库：**

```bash
pip install qrcode[pil]
```

### 前端

**患者管理页面：**

- 组件：`PatientQrcodeDialog.vue`
- 功能：显示患者二维码、支持下载

**患者登录页面：**

- 文件：`PatientLoginPage.vue`
- 功能：摄像头扫码识别
- 依赖：`html5-qrcode` 库

**依赖库：**

```bash
npm install html5-qrcode
```

## 二维码格式

```
PATIENT_QRCODE:P20260315001
```

- 前缀：`PATIENT_QRCODE:` - 标识为患者二维码
- 后缀：患者编号（patient_no）

## 安全说明

1. 二维码仅包含患者编号，不包含敏感信息
2. 扫码登录需要验证患者编号是否存在
3. 登录操作会记录审计日志
4. 建议定期更换患者二维码（重新生成）

## 注意事项

1. 摄像头需要HTTPS环境（本地开发http://localhost可以）
2. 首次使用需要授权浏览器访问摄像头
3. 二维码清晰度要足够，避免模糊或损坏
4. 扫码时保持二维码在摄像头视野中心
